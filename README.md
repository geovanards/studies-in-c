# C Programming Studies

Welcome to my C programming studies repository! Here, I am learning and practicing various concepts of the C language. This repository contains several code examples and exercises I am working on to improve my C programming skills.

## Contents

- **Basic Syntax**: Learning about data types, variables, input/output functions, and basic control structures.
- **Control Flow**: Using conditional statements (`if-else`), loops (`for`, `while`), and `switch-case`.
- **Functions**: Declaring and defining functions, passing arguments, and returning values.
- **Arrays and Strings**: Working with arrays and manipulating strings.
- **Pointers**: Understanding pointers, memory management, and pointer arithmetic.
- **Structures**: Creating and manipulating structures.
- **File Handling**: Performing basic file read and write operations.
- **Dynamic Memory Allocation**: Using `malloc()`, `free()`, and `realloc()`.
- **Algorithms**: Implementing common algorithms (like sorting and searching) in C.
